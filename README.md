# Steps to run project

> **Note**: Make sure you have completed the [Mongo DB Installation](https://www.mongodb.com/docs/manual/installation/) guide before proceeding, and Mongo DB is running successfully.

## Step 1: Install modules
First you will need to install modules, go to root of the project and run:

```sh
# Using npm
npm install

# OR using Yarn
yarn yarn
```

## Step 2: Start Metro

Then, start server by running command: 

```sh
# Using npm
npm start

# OR using Yarn
yarn start
```
IP address of server will be shown in terminal, that is reuired to be entered in APK.

## Step 3: Download Cat Fact Apk

Download [Cat Fact Apk](https://drive.google.com/file/d/1S18GdBKIfpq_vakqQGp8Eu3kBN3eMOR9/view?usp=sharing) and install it in Android device.

## Step 4: Test APIs working through APK

Enter server IP address on opening of APK, after that APK will unlock and will start working & communicating with server.
